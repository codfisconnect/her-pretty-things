# Her Pretty Things

Her Pretty Things is a React e-commerce storefront for cute, feminine, and Kawaii-inspired products.

## Planned technology stack

- Frontend: React, TypeScript, Vite, React Router, and lucide-react
- Backend: Node.js and Express
- Database: PostgreSQL with Prisma
- Payments: Razorpay

The backend, database, authentication, payments, and admin features are scaffolded only and will be implemented later.
